# src/styles

- `fonts.css` — self-hosted fonts (npm @fontsource packages).
- `tokens.css` — design tokens of the base identity (light + dark). Themes override them.
- `global.css` — reset, typography, page layout, print and reduced-motion rules (cascade layers).
- `pages/` — optional page-specific stylesheets, used via the `styles` frontmatter field.

See docs/THEMES.md.
