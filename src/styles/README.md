# src/styles

- `fonts.css` — self-hosted fonts (npm @fontsource packages).
- `tokens.css` — design tokens of the base identity (light + dark). Themes override them.
- `global.css` — layer order, reset, base typography, print and reduced-motion rules.
- `layout.css` — centred symmetric page grid, reading sheet, blurred page artwork.
- `components.css` — shared UI classes (`.pill`, `.badge`, `.entry-card`, `.block-heading`…).
- `pages/` — optional page-specific stylesheets, used via the `styles` frontmatter field.

See docs/THEMES.md.
