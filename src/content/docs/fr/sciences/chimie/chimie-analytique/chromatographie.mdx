La <Term id="chromatographie">chromatographie</Term> regroupe des techniques qui **séparent les
constituants d’un mélange** selon leur affinité pour deux phases : une phase *mobile* qui se déplace
et une phase *stationnaire* qui reste fixe.

<Callout type="definition">
  Chaque constituant migre à sa propre vitesse : ceux qui « accrochent » le plus la phase
  stationnaire avancent le moins vite.
</Callout>

## Les grandes familles

- **Sur couche mince / papier** : simple et peu coûteuse, idéale pour l’enseignement.
- **En phase gazeuse** : pour les composés volatils (stupéfiants, accélérants d’incendie).
- **En phase liquide (HPLC)** : pour les molécules fragiles ou peu volatiles.

<Callout type="example">
  En police scientifique, on compare le chromatogramme d’un échantillon à celui de substances de
  référence pour identifier un produit.
</Callout>
